# `ScannedSystem`

Details of a system was that scanned.

## Properties

- `symbol` **string** *(required)* — Symbol of the system.
- `sectorSymbol` **string** *(required)* — Symbol of the system's sector.
- `type` **[SystemType](../schemas/SystemType.md)** *(required)*
- `x` **integer** *(required)* — Position in the universe in the x axis.
- `y` **integer** *(required)* — Position in the universe in the y axis.
- `distance` **integer** *(required)* — The system's distance from the scanning ship.
