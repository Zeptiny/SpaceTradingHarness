# `PublicAgent`

Public agent details.

## Properties

- `symbol` **string** *(required)* — Symbol of the agent.
- `headquarters` **string** *(required)* — The headquarters of the agent.
- `credits` **integer (int64)** *(required)* — The number of credits the agent has available. Credits can be negative if funds have been overdrawn.
- `startingFaction` **string** *(required)* — The faction the agent started with.
- `shipCount` **integer** *(required)* — How many ships are owned by the agent.
