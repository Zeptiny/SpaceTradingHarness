# `ShipCargo`

Ship cargo details.

## Properties

- `capacity` **integer** *(required)* — The max number of items that can be stored in the cargo hold.
- `units` **integer** *(required)* — The number of items currently stored in the cargo hold.
- `inventory` **[ShipCargoItem](../schemas/ShipCargoItem.md)[]** *(required)* — The items currently in the cargo hold.
