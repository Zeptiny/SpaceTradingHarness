# `Construction`

The construction details of a waypoint.

## Properties

- `symbol` **string** *(required)* — The symbol of the waypoint.
- `materials` **[ConstructionMaterial](../schemas/ConstructionMaterial.md)[]** *(required)* — The materials required to construct the waypoint.
- `isComplete` **boolean** *(required)* — Whether the waypoint has been constructed.
