# `Meta`

Meta details for pagination.

## Properties

- `total` **integer** *(required)* — Shows the total amount of items of this kind that exist.
- `page` **integer** *(required)* — A page denotes an amount of items, offset from the first item. Each page holds an amount of items equal to the `limit`.
- `limit` **integer** *(required)* — The amount of items in each page. Limits how many items can be fetched at once.
