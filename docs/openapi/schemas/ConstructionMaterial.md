# `ConstructionMaterial`

The details of the required construction materials for a given waypoint under construction.

## Properties

- `tradeSymbol` **[TradeSymbol](../schemas/TradeSymbol.md)** *(required)*
- `required` **integer** *(required)* — The number of units required.
- `fulfilled` **integer** *(required)* — The number of units fulfilled toward the required amount.
