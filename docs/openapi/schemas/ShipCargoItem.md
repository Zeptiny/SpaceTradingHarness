# `ShipCargoItem`

The type of cargo item and the number of units.

## Properties

- `symbol` **[TradeSymbol](../schemas/TradeSymbol.md)** *(required)*
- `name` **string** *(required)* — The name of the cargo item type.
- `description` **string** *(required)* — The description of the cargo item type.
- `units` **integer** *(required)* — The number of units of the cargo item.
