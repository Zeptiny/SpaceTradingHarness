# `Chart`

The chart of a system or waypoint, which makes the location visible to other agents.

## Properties

- `waypointSymbol` **[WaypointSymbol](../schemas/WaypointSymbol.md)** *(required)*
- `submittedBy` **string** *(required)* — The agent that submitted the chart for this waypoint.
- `submittedOn` **string (date-time)** *(required)* — The time the chart for this waypoint was submitted.
